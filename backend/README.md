# TaskFlow

TaskFlow is a small task-management web application created as a synthetic software project for an AI-agent certification capstone.

## Stack
- React + Vite (frontend)
- FastAPI + SQLAlchemy (backend)
- SQLite (development database)
- JWT authentication

## Purpose
The application will later be handed to an AI agent whose job is to perform a deployment-readiness review. The capstone will compare at least two agent runs and document the feedback loop.
